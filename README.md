# 🎨 Cambiador de Color de Fondo

Este proyecto es una pequeña aplicación web que cambia dinámicamente el color de fondo de la página usando una paleta de colores oscuros predefinida.

## 📁 Archivos principales

### `index.html`
Estructura principal de la interfaz, incluye:
- Un botón para activar el cambio de color.
- Un elemento `<span>` que muestra el código HEX del color aplicado.

### `styles.css`
Define los estilos visuales de la aplicación:
- Paleta de colores en variables CSS.
- Fondo oscuro, botones con estilo degradado.
- Diseño centrado y accesible.

### `script.js`
Lógica JavaScript que permite:
- Seleccionar un color aleatorio del arreglo `darkColorsArr`.
- Aplicar el color como fondo del `<body>`.
- Mostrar el código del color en pantalla.

## 🚀 Cómo usar
1. Abre `index.html` en tu navegador.
2. Haz clic en el botón para cambiar el color de fondo.
3. El código del color actual se mostrará en pantalla.
